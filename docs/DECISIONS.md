# V1 决策记录

## 已采用

- 附录 A 仅给出 `Secret.lie_script` 的 `act/probe/answer`；Schema 按示例保留这三个字段。
- P0 曾简化搜证；P1 改为玩家选搜查目标，按线索成本、地点容量、前置线索和每幕预算校验。目标名称在获得前可见，线索正文仍在搜得后显示。
- `GameState` 由 SQLite 事件流重放；P1 另加 LangGraph 节点 checkpoint，用于单回合图状态排查与恢复，不代替事件事实来源。
- 对局中 NPC 的事件视图仅含 `observable`，不包含真相动作或隐藏描述。
- P2 的 NPC 生成接口仅接收 `PerceptionView`；历史声明以 `CLAIM` 事件追加，L3 只呈现角色可见的声明文本。
- P2 输出闸先用授权 ID、禁说三元组和泄密表近似匹配，再在配置模型时走 LiteLLM 语义判定。语义判定出错时回避回答。
- P3 摘要使用可重算的事件摘录，按公共与角色视角分别存储；原始事件与声明不删除。`CONTEXT_MODE=auto` 默认仅在字符近似预算超限时启用摘要；`full/layered` 用于 A/B 对照。
- P4 质检的 `optimal_path_clue_ids` 是结构图上的最低搜证成本路径，仍标记 `requires_human_review=true`，不能替代语义可解性人工判断。
- P5 主动发言由公开轨迹和公开角色卡确定；没有模型时 NPC 使用角色内回避文本，节奏路径仍可确定性测试。
- P6 离线模拟器以轮换指认建立回归基线；其通关率不代表玩家推理能力。模型模拟与 judge 通过 LiteLLM 调用，泄密仍由程序闸判定。
- P7 同局双席只验证席位归属与可见性，不开放实时多人房间。未知 `EventType` 可落库，旧消费端忽略。V1 发布只支持本格/变格 profile。
- V1 API 在单机模式提供 JSON 回合结果；请求 SSE 时发送完成事件，不提供逐 token 流式输出。API 绑定本机地址运行，开放到局域网时应配置 `API_TOKEN`。
- 胜利条件中的动机目前用真凶私有目标的词片交集判定，属于结构化兜底；语义判分需要已配置模型并经人工校准后才能作为正式指标。

## 待确认

- SPEC 4.5 要求 `CONFRONT → VOTE`，而 P0 流程文字简写为 `SEARCH → VOTE`。本实现按正式转移表，在 UI 通过公聊进入指认。
- SPEC 4.3/5.2 的 `Secret` 使用 `Triple`、`LieTurn`，但 5.2 未定义两者字段；按附录 A 的三元组与 `act/probe/answer` 解析。
- 附录 A 把 E02 的投毒时间设为 t=-90（21:40），前言称实际死亡约 21:42；本实现不修订原始事实。
- 附录 A 省略地点、关系、泄密表和来源；P0 fixture 的补全内容需剧本作者核对。
- SPEC 第 12 章把完整阶段机列入 P1、三层隔离列入 P2；本轮任务明确要求两者的 P0 最小版，故以任务范围为准。
- 默认环境未配置 `LLM_MODEL`；已用本机 `qwen3.5:2b` 做四局短测，但最终输出的独立语义泄密率和连续追问自然度仍未达到可验收样本量。
- SPEC 8.3 的 G1 要求对所有案件事实断言做语义溯源；当前实现只对越权 ID 做确定性检查，非 ID 的臆造事实仍需后续完善。
- P3 已用本地 2B 模型做一次合成快照 A/B；真实长局的回答一致性、费用和 p95 延迟仍未测量，静态 token 对比不能证明保真收益。
- 本地 `qwen3.5:2b` 的一份合成长历史 A/B 中，分层摘要的实际输入 token 高于全量历史（2595 对 2050），说明字符近似估算不可当成本结论；需在真实长局、多个模型上重测保真与费用。
- 附录 A 未提供 `linter_report.solvability.optimal_path_clue_ids`，复盘显示从 IR 关联推导的参考证据集，不称为最优路径。
- P4 的陌生剧本编译速度与准确率尚无法验收：本机虽有 2B 模型，但没有两份获授权的外部测试剧本。已用 mock 抽取和完整 IR 上传验证流程。
- P6 的 3 剧本 × 20 局与 judge κ>0.6 需要至少两份外部获授权剧本、可用且已校准的模型和 20 组人工标签；当前仅有《雾港谜案》的 20 局离线报告与四局模型短测。
- 本地 `qwen3.5:2b` 四局真实模型抽样的原始候选风险命中率为 41.5%（含检测器误报），不能当成最终输出泄密率；门禁仍按保守阈值判失败，需人工复核并换更强模型重测。
- 自然语言剧本的解析质量、内容分级漏检率，以及语义裁判准确率尚未用外部样本验证；当前报告是工程闭环验收，不等同于这些质量指标达标。
