# V2 迭代状态

当前为 V2.0-beta。只有通过 [V2 说明书](V2_SPEC(1).md) 1.6 的全部退出条件后才进入 V2.5；V3、V4、V5 依次同理。V1 固定版本在独立检出目录运行，不随本目录改动。

## 已落地的工程能力

- IR 1.1 可选难度、分级、标签、解析来源与导演配置；V1 的 1.0 fixture 保持可读。剧本表增加内容哈希、版本与归档元数据。
- PDF 页码分段，长文档逐段实体扫描；每个字段保留来源、置信度、部分抽取结果和格式错误。校对页支持逐字段保存、引用查看、版本记录与回退。
- 质检显示最短关键线索成本、预算、多解、红鲱鱼比例与难度估计，发布门禁阻止结构错误。
- 上传记录作者确认的授权来源与时间；PII 与相似文本进入人工复核。未解决的复核项阻止发布。
- 编译、评测任务使用 SQLite 状态表与后台单工作线程；V2 API 支持提交、轮询、失败重试及幂等键。剧本库支持筛选、版本查询、下架和草稿删除；下架不影响已有对局。
- 模型路由、编译缓存、请求哈希与调用汇总；评测局保存失败归因，并提供三剧本回归入口。回合 SSE 输出节点进度，正文只在输出闸之后发送；带幂等键的请求可用 `Last-Event-ID` 续传已保存的事件。
- SQLite WAL 与 10 局并行测试；UI 显式按席位读取状态。裁判按席位验证证据，返回判项理由。角色视角回放需作者令牌并写审计。
- 玩家推理板按已获线索显示关系、证据依赖和可见事件时间线；复盘报告列出参考证据路径、未发现及未提交的线索。

- `uv run pytest -q`：137 passed。10 局并行事件序号连续，私密线索未串局；两幕转移、回放、异步任务恢复、SSE 续传、包导入、角色陈述审批与幕次边界、授权范围变更及 27 个注入/越权输出案例通过。
- V2 剧本库、校对页和实际对局在桌面 1440×900 与手机 390×844 视口通过 Playwright 渲染检查，无水平溢出。
- 12 页公开 PDF 逐页扫描后的本地 4B 完整编译耗时 516 秒，仍有多项字段错误。改为逐页抽角色后，4B 与 9B 均能得到 8/8 个有效角色，但全字段仍未通过发布门禁；4B + 9B 修复轮次耗时 1057 秒且未通过。公开素材只用于测试，未并入产品库。
- 本机 9B 四局烟测：3/4 通关，正常策略 2/3，41 个探针最终命中 0，p95 回合延迟 9052ms；样本量和速度均不满足正式门禁。见 [烟测报告](V2_9B_SMOKE.md)。
- 9B 模拟玩家 + 4B 其余节点的四局烟测仍为 3/4 通关、正常策略 2/3，p95 15572ms；路由未改善质量或延迟，见 [混合模型报告](V2_MIXED_SMOKE.md)。
- 2026-11-03 网络复查：可检索公开仓库索引，但 GitHub 克隆及两处 CC BY 素材直连仍超时；尚未取得可合法改编并纳入发布库的完整外部文件。
- 用户随后提供 5 本带角色、线索和 GM 真相的本机材料；2026-11-03 明确允许使用及发布，现有草稿授权状态已更新。导入器修复角色陈述截断并纳入全部可阅读 txt，候选陈述由 348 条增至 1,549 条，保持未批准；两本重点本补了候选 IR 并通过结构 lint，但 4B 四局烟测均为 0/4 指认真凶，内容校对与正式评测仍未完成，见 [导入状态](V2_USER_CORPUS_STATUS.md)。

## 未通过的退出条件

- 已有两份来源完整且获用户使用与发布许可的外部候选草稿，但尚未完成内容校对；正式可发布 IR 仍只有一份内置本。3 剧本各 20 局、作者校对中位数 <15 分钟尚无结果。
- 本机 4B/9B 对完整陌生本抽取仍失败；长文档覆盖率的结构测试通过，不代表关键字段定位准确率达到 90%。
- 需要真人完成 100 条 NPC 输出与全部探针的语义复核、20 组 judge 双人标注、三本各 10 项质检标注；不得以模型自评代替人工 κ 或一致率。
- 目标 7B 级模型的单局人民币成本尚未实测；本机 9B 烟测 p95 9052ms，未达到 <3s。自动化测试数已达到 ≥120 的工程门槛。
- SSE 有节点进度、断线后事件续传；安全文本片段在输出闸后发送，原始模型 token 不能在安全检查前外发，因此尚非实时逐 token 生成。
- 语义动机裁判、完整证据链可解性、真实长局压缩收益及作者身份权限尚未达到说明书门槛。

因此当前不能标记为 V2 正式版，也不能进入 V2.5。人工授权与标注项目等待可执行输入，工程改进可继续进行。
