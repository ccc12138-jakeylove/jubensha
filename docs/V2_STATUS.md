# V2 迭代状态

当前为 V2.0-beta。只有通过 [V2 说明书](V2_SPEC(1).md) 1.6 的全部退出条件后才进入 V2.5；V3、V4、V5 依次同理。V1 固定版本在独立检出目录运行，不随本目录改动。

## 已落地的工程能力

- IR 1.1 可选难度、分级、标签、解析来源与导演配置；V1 的 1.0 fixture 保持可读。剧本表增加内容哈希、版本与归档元数据。
- PDF 页码分段，长文档逐段实体扫描；每个字段保留来源、置信度、部分抽取结果和格式错误。校对页支持逐字段保存、引用查看、版本记录与回退。
- 质检显示最短关键线索成本、预算、多解、红鲱鱼比例与难度估计，发布门禁阻止结构错误。
- 上传记录作者确认的授权来源与时间；PII 与相似文本进入人工复核。未解决的复核项阻止发布。
- 编译、评测任务使用 SQLite 状态表与后台单工作线程；V2 API 支持提交、轮询、失败重试及幂等键。剧本库支持筛选、版本查询、下架和草稿删除；下架不影响已有对局。
- 模型路由、编译缓存、请求哈希与调用汇总；评测局保存失败归因，并提供三剧本回归入口。回合 SSE 输出节点进度，正文只在输出闸之后发送；带幂等键的请求可用 `Last-Event-ID` 续传已保存的事件。
- SQLite WAL 与 10 局并行测试；UI 显式按席位读取状态。裁判按席位验证证据，返回判项理由。角色视角回放需作者令牌并写审计。
- 玩家推理板按已获线索显示关系、证据依赖和可见事件时间线；复盘报告列出参考证据路径、未发现及未提交的线索。

## 交接问题修复（2026-11-03）

- **动机裁判**：`judge_submission` 不再用关键词包含直接判过。新增子句级否定识别
  （“没有发现/并非为了/不是为了”，并处理“不得不/并非不/不仅”等双重否定与
  非否定用法）、真凶一致性、约定动机证据和证据语义关联检查；判项理由会写明
  否定、缺证据或指认错误。新增 `tests/test_referee_semantics.py` 覆盖交接中的
  原句“并非为了自保，也没有发现毒酒”。
- **多幕隔离**：IR 增加 `Character.private_goals_by_act` 与
  `Script.act_scope_reviewed`。导入器按幕保存角色目标，`private_goals` 只保留
  第一幕；`build_perception` 只注入当前幕及此前幕目标。线索表若没有按幕分组，
  保守归入第一幕并产生 `MULTI_ACT_SCOPE_UNREVIEWED` 校对项；作者须通过
  `act_clues` 逐幕配置。质检新增 `CLUE_REVEALS_LATER_ACT` 阻断项，防止第一幕
  线索直接揭示后续幕事件；角色目标未分幕且未确认 `act_scope_reviewed` 时产生
  `MULTI_ACT_GOAL_SCOPE_UNREVIEWED` 警告。
- **模拟玩家**：移除投票提示中的“欠条”等剧本专用规则；无效模型输出不再按
  “线索里角色名字出现次数”猜人，而是显式记录 `invalid_model_vote` 并退回
  本人角色；提示版本升级为 `simulator.vote_plan.v2` / `simulator.search_plan.v2`。
  评测报告新增“模拟玩家无效投票率”。
- **可复现数据**：新增完全合成的双幕可共享测试本 `fixtures/multiact_demo.json`
  与 `fixtures/local_corpus_manifest.json`（只含结构与 SHA256）。本机五本素材
  可用 `scripts/verify_local_corpus.py` 校验；正文与 `local_reviews/` 仍需另行
  交付，说明见 `docs/LOCAL_CORPUS_MANIFEST.md`。

## 未通过的退出条件

- 已有两份来源完整且获用户使用与发布许可的外部候选草稿，但尚未完成内容校对；正式可发布 IR 仍只有一份内置本。3 剧本各 20 局、作者校对中位数 <15 分钟尚无结果。
- 本机 4B/9B 对完整陌生本抽取仍失败；长文档覆盖率的结构测试通过，不代表关键字段定位准确率达到 90%。
- 需要真人完成 100 条 NPC 输出与全部探针的语义复核、20 组 judge 双人标注、三本各 10 项质检标注；目前《东方之星号游轮事件》最新四局已导出 33 条 NPC、26 条探针、4 条 judge 待标注，不得以模型自评代替人工 κ 或一致率。
- 目标 7B 级模型的单局人民币成本尚未实测；本机 9B 烟测 p95 9052ms，未达到 <3s。自动化测试数已达到 ≥120 的工程门槛。
- SSE 有节点进度、断线后事件续传；安全文本片段在输出闸后发送，原始模型 token 不能在安全检查前外发，因此尚非实时逐 token 生成。
- 语义动机裁判已改为确定性否定/证据关联规则，但尚未用 20 组双人标注计算 κ；
  `scripts/calibrate_judge.py` 仍需要真实人工标签，不能用模型自评替代。
- 合成双幕本单局真实模型烟测：1/1 通关，`invalid_model_votes=0`；这只是修复
  回归，不是三本各 20 局的正式验收。除《怒海余生》外的本机多幕素材仍未逐幕
  配置，导入后只能作为草稿，不能发布或试玩。
- 《怒海余生》已完成逐幕配置并有本地 reviewed IR，但真实模型两局 0/2 指认
  真凶，尚未达到“可玩基准本”的证据门槛；需要改进搜证规划与动机归因后再跑
  多 persona × 多局。`local_reviews/` 为本地交付，不进入仓库。
- 完整证据链可解性、真实长局压缩收益及作者身份权限尚未达到说明书门槛。

因此当前不能标记为 V2 正式版，也不能进入 V2.5。剧本使用与发布许可已确认；内容质量、目标模型性能与人工标注仍未过线。
